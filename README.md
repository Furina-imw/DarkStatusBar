An Xposed module designed to force the status bar to remain in dark, dim, or gray mode—as desired—on Xiaomi phones, to prevent “Burn-in” on OLED screens that haven’t yet experienced this issue or are about to. The downside is that this may cause visual discomfort for users, but you can still view the status bar normally in the Control Center or on the lock screen. 

The only device tested was the Mondrian. HyperOS 3, Android 15, TW
