An Xposed module designed to force the status bar to remain in dark, dim, or gray mode as desired on Xiaomi phones, in order to prevent “burn-in” on OLED screens that have not yet experienced or are about to experience this issue. The trade-off is that this may cause visual discomfort for users, but you can view the status bar normally in the Control Center or on the lock screen. 

The only device tested was the Mondrian.
